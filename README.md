# FuelLog ⛽

レシートとメーターをカメラで読み取る燃費計算 Android アプリです。

## 機能

- 🧾 **給油レシートをカメラで読み取り**(給油量 / 金額 / 単価を自動抽出)
- 🚗 **オドメーター(総走行距離)・トリップメーター(区間距離)をカメラで読み取り**
  - オドメーター値はメモとして全レコードに保存されます
- 🖼️ **過去に撮影した写真からも読み取り可能**(ギャラリー選択)
- ✏️ 読み取ったデータは全項目 **確認画面で修正可能**
- 📅 日付は読み取った日を自動入力(手動変更可)
- 📋 燃費を **表形式** で表示(平均に応じた色分け、CSVエクスポート対応)
- 📈 燃費の推移を **グラフ** で表示(1か月 / 6か月 / 1年 / 全期間、平均線付き)

## 燃費の計算ルール

1. トリップメーターの値を優先して使用
2. トリップ未入力時は、前回記録とのオドメーター差分から走行距離を算出
3. 燃費 = 走行距離 ÷ 給油量

## 技術構成

| 項目 | 採用技術 |
|---|---|
| 言語 / UI | Kotlin + Jetpack Compose (Material 3) |
| OCR | ML Kit Text Recognition v2(日本語 + ラテン数字、オンデバイス処理) |
| カメラ | CameraX |
| DB | Room (SQLite) |
| グラフ | Compose Canvas(自前実装・外部依存なし) |
| ビルド | GitHub Actions |

## APK のビルド方法

### 方法 A: GitHub Actions(推奨)

1. このリポジトリを GitHub に push する
2. リポジトリの **Actions** タブを開く
3. 「Build APK」ワークフローの完了を待つ
4. 実行結果ページ下部の **Artifacts** から `FuelLog-debug-apk` をダウンロード
5. ZIP 内の `app-debug.apk` を Android 端末に転送してインストール
   (「提供元不明のアプリのインストール」を許可してください)

手動実行したい場合は Actions タブの「Build APK」→「Run workflow」からいつでもビルドできます。

### 方法 B: Android Studio

1. Android Studio(Ladybug 以降推奨)でこのフォルダを開く
2. Gradle Sync 完了後、**Build > Build App Bundle(s) / APK(s) > Build APK(s)**
3. `app/build/outputs/apk/debug/app-debug.apk` が生成される

### 方法 C: コマンドライン

Gradle 8.9 がインストール済みの環境で:

    gradle assembleDebug

Gradle Wrapper を使いたい場合は、まず一度だけ `gradle wrapper` を実行して
`gradlew` / `gradle-wrapper.jar` を生成してください(バイナリのため本リポジトリには未同梱)。

## 注意事項

- 初回の OCR 実行時に、認識モデルが Google Play 開発者サービス経由でダウンロードされます
  (インストール時の自動ダウンロードも設定済み)。以降はオフラインで動作します。
- 燃費は簡易計算(走行距離 ÷ 給油量)です。正確な満タン法を厳密に管理する場合は、
  満タン給油のタイミングで記録してください。
- OCR の読み取り精度はレシートのレイアウトに依存します。保存前の確認画面で必ず値を確認してください。
